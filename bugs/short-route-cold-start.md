# 目前位置到芝山規劃等待過久

- 功能：選擇起點或捷運站後規劃路線，應避免等到按下規劃才開始載入整份路網。
- 數據：使用公開模擬座標 25.10834, 121.53284 至芝山站；隔離冷啟動一次測試約 14.8 秒，其中施工資料讀取約 9.9 秒、主路線與候選比較依序運算。沒有讀取使用者的真實位置。
- 原因：首次路網初始化與施工資料冷讀在使用者規劃時才完成；同一次人行道候選的多條路線各自重建道路、面積、施工及阻擋點索引。
- 修復：使用者開始選擇起終點或查看捷運站時，在背景預先準備後端路網及施工資料；同一次候選比較共用不變的驗證索引，各候選仍逐段獨立驗證。施工資料仍須新鮮，來源變更、失效及分鐘變更仍會重新檢查或重建。
- 驗證：模擬選擇地點花 3 秒後按規劃，主路線約 3.3 秒、候選比較約 1.4 秒，3 條候選均通過獨立驗證；暖機本身約 5.8 秒並與選擇操作重疊。單次本機結果不代表所有裝置、網路或正式環境。
