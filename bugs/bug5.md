# BUG-05：通行設定誤稱路線避開所有車道

- 類別：介面資訊
- 重現版本：`6112846`，含備援修復 `b994c10`
- 狀態：已修正；獨立本機服務的桌面瀏覽器已重測，設定面板顯示新文案

## 功能與重現

在「規劃路線」按「調整通行偏好」，面板顯示「規劃時避開車道與階梯」。但符合條件的人車共道可在預設路線中使用，這句話可能讓使用者誤以為路線完全不會與車輛共用道路。

## 資料與相關程式

`src/routing.mjs` 的 `edgeAllowed` 在 `eligibleSharedRoad(way, evidence)` 通過且未限定官方圖資時允許共道路段；路線結果畫面也有共道警示。原文案位於 `src/App.jsx` 的通行設定面板：

```jsx
<p className="quiet-note">規劃時避開車道與階梯。</p>
```

## 修復

改為「規劃時避開階梯；必要時可能使用人車共道，請留意車輛與現場狀況。」使設定說明與既有路線政策一致。此修改不改變路由規則，也不表示共道路段已確認無障礙。
