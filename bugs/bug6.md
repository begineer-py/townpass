# BUG-06：搜尋去重隱藏不同座標的同名地點

- 類別：功能／資料
- 重現版本：`a2b5371`
- 狀態：已修正並完成桌面瀏覽器驗證

## 功能與重現

搜尋「附中公園」。資料包含官方 `w4-258`（25.0363407, 121.5422592）及 OSM `osm-w403554089`（25.0364494, 121.5422382），原搜尋結果只保留其中一筆，使用者無法選取另一個位置。這兩個點相距約 12 公尺，不能假定是同一個已確認入口。

以大安森林公園站為起點選到官方點時，瀏覽器回報無法接入；混合樣本使用的 OSM 點則是另一筆資料，兩次結果不能直接比較。施工和偏好也可能影響路由。

## 相關程式碼及原因

`src/App.jsx` 原來將同名地點的緯經度四捨五入至小數第三位作為去重鍵：

```js
normalize(p.name) + Math.round(p.lat * 1000) + Math.round(p.lon * 1000)
```

不同位置因此可能被合併，且哪筆保留受排序影響。

## 修復方法

同一 ID 或同名且精確座標相同的重複紀錄仍去重；同名但座標不同的地點保留，並在同名結果顯示資料來源供區分。資料點本身不代表現場入口或無障礙狀態；路由仍須通過既有驗證與提示。

## 驗證

獨立服務重載後，兩筆搜尋結果分別顯示其他圖資與 OpenStreetMap。選 OSM 地點，由大安森林公園站規劃成功，畫面顯示 19 公尺入口估算與人車共道提示。`npm run build` 通過。
