# BUG-09：較早的單次定位可能覆蓋使用者選定的起點

- 類別：定位／競態
- 基底版本：`2c45fa0`；另含 `30b7bcb` 提示修復
- 狀態：依程式流程修正；尚未在瀏覽器延遲定位或真實裝置重現

## 功能與重現條件

啟動時自動定位仍在等待期間，選取示範路線或以句子規劃。若先前的高精度定位回覆晚於使用者選點，原本可能把起點覆蓋為目前位置，卻保留依示範起點規劃的結果。交換端點或載入舊行程也有相同風險。

## 資料與相關程式

`locate(null, true)` 接受相同 `locationRequest` 的結果後執行 `setStart(p)`；原 `runDemo`／`calculate` 沒有更新該序號。此問題由程式狀態及非同步流程確認，尚無實機定位延遲的瀏覽器證據。

```js
if (locationId !== locationRequest.current) return;
if (useAsStart) { cancelNearby(); setStart(p); }
```

## 修復與驗證

在已選定起終點後開始規劃、交換端點、載入行程或手動選點時使未完成的單次定位失效，並只允許目前請求清除定位中狀態；目的地導覽等待定位時也忽略過時錯誤。定位與回線相關定向測試 21 項通過、建置通過；實際裝置延遲回覆仍需驗證。
