# BUG-16：手機全圖視角的部分路線缺口標籤重疊

- 類別：地圖／手機介面
- 重現版本：`aa8a4c4`
- 狀態：已修正，手機瀏覽器重測通過

## 重現

390 × 844 手機畫面、輪椅設定，規劃大橋頭站到大直站。完整路線無法連通，系統顯示兩側部分路段及約 134 公尺缺口。預設全圖視角下，兩個缺口標籤互相覆蓋，起點側文字被蓋住；放大後可辨認，但無法同時看到兩段完整路線。下方面板文字仍可辨別兩側，並非缺口被誤畫成路線。

## 程式與修復

`src/MapView.jsx` 原本兩個缺口標記都把永久標籤放在上方：

```js
bindTooltip(label, { permanent: true, direction: 'top' })
```

改為起點側上方、目的地側下方，並與標記留間距；不修改部分路線幾何、施工或禁行檢查。仍需實際測試不同方向與距離，不可推論所有視角都沒有遮擋。

## 驗證

390 × 844 手機瀏覽器重測大橋頭到大直，預設全圖的起點側與目的地側標籤分別在上下方，兩者完整可讀；仍顯示約 134 公尺未連接。此為單一路線、單一視角的結果。
