# BUG-17：有部分路線時自動附近位置搜尋被跳過

- 類別：路線恢復／功能
- 重現版本：`aa8a4c4`
- 狀態：已修正，手機瀏覽器重測通過

## 重現與結果

輪椅設定下規劃大橋頭站到大直站，完整路線失敗後畫面顯示兩段未連接的部分路線；等待後只有捷運出口建議及「重新搜尋附近人行路網位置」，未自動列出附近人行路網候選。手動按重新搜尋後，出現起點 7／16 公尺及目的地 9／42 公尺等候選，兩段部分路線仍在。這與先前失敗後自動搜尋候選的功能不一致；候選不代表完整路線或確認入口。

## 程式與原因

`src/App.jsx` 的自動搜尋 effect 對已存在部分路線直接返回：

```js
if (partialRoute || !shouldAutoSearchNearby(/* state */)) return;
```

因此即使符合失敗後搜尋條件，也不啟動候選搜尋。

## 修復

不因存在部分路線而跳過自動搜尋；保留既有錯誤類型、網路與施工資料限制。候選搜尋結果仍獨立於部分路線，必須驗證搜尋過程與結果不會清除兩段，也不把候選當作完整抵達。

## 驗證

390 × 844 手機瀏覽器重測大橋頭到大直，未手動按重新搜尋；部分路線顯示後即自動搜尋，出現起點 7／16 公尺及目的地 9／42 公尺候選，兩側路段和約 134 公尺未連接提示仍保留。搜尋結果仍標示入口及通行未確認。
