# BUG-08：替代起終點在規劃失敗時沒有原地點警示

- 類別：功能／資訊提示
- 重現版本：`2c45fa0`
- 狀態：已修正，桌面瀏覽器重測通過

## 重現與結果

以大橋頭站為起點、大直站為終點，規劃失敗後搜尋附近人行路網位置，選取距起點約 7 公尺的候選。重新規劃仍失敗時，畫面起點變成「附近人行路網位置」，目的地仍是大直，但沒有顯示原起點名稱、距離或兩者之間的通行未確認。使用者因此難以辨認選取的替代位置與原起點的關係。

## 相關程式碼

替代點的原始名稱與直線距離由 `nearbyReplacement` 保存，但 `src/App.jsx` 原本只在 `route` 有值時顯示：

```jsx
{route && <>{nearbyWarnings(start,end).map(/* warning */)}</>}
```

因此重算中或路線失敗時，提示隨路線結果消失，資料仍留在端點物件中。

## 修復方式

讓端點存在替代點資料時持續顯示 `nearbyWarnings`，包含規劃中、失敗及成功狀態；更換端點後依現有端點狀態移除提示。不改變位置、路由或安全驗證。

## 驗證

大橋頭到大直的候選起點重測中，規劃期間與失敗後都顯示距原大橋頭約 7 公尺及通行未確認提示；改選圓山站後提示消失。`npm run build` 通過。
