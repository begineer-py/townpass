# 路線規劃等待過久

- 功能：規劃時須等待已驗證路線與自動比較完成，不能先顯示尚未確認的暫時路線。
- 資料：本機以南港展覽館至南港軟體園區的公開站點及即時施工資料測量。調整前後端冷啟動約 7.4 秒，調整後約 4.9 秒；均回傳同一組出口及 696 公尺路線。此為單次本機測量，不代表所有路線或正式環境。
- 原因：施工資料讀取後才初始化路網；一般搜尋也先建立官方繞路索引。外部路線及自動比較缺少較短的等待上限。
- 修復：施工讀取與單一後端路網初始化並行；需要官方繞路時才建立索引；外部查詢與自動比較設時限，逾時採用原有通過驗證的備援路線，不釋出未驗證結果。
- 驗證：測試涵蓋預熱共用、取消與初始化失敗、外部服務逾時及自動比較取消；另以真實路網與施工資料做冷啟動前後測量。
