# BUG-11：施工清單隱藏同工程不同的時間說明

- 類別：資料呈現
- 版本：`2c45fa0`，包含後續定位與替代點提示修復
- 狀態：已修正，瀏覽器重測中

## 重現

手機尺寸開啟信義示範，在規劃中將終點改為象山站後重新規劃。沿途施工清單有兩筆顯示相同松仁路工程及日期，看似重複，畫面沒有顯示來源中不同的施工時間說明。

## 資料與原因

2026-11-07 的施工 API 中，`11501474-1` 的 `hours` 是「自00時00分至24時00分」；`11501474-2` 另有「依交維計畫訂定時間施工」。兩筆同工程但時間文字不同，原分組因 `hours` 不同而保留，`src/App.jsx` 卻只顯示地址、日期和替代方案，沒有顯示時間。不能僅憑相同畫面文字把兩筆當作重複資料刪除。

```jsx
{c.start}—{c.end}
{c.plan || "通行影響請依現場指引確認。"}
```

## 修復

施工清單在來源有提供 `hours` 時顯示「施工時間」及原文，讓不同紀錄的差異可辨認。不修改來源資料、施工封閉判斷或路由演算法。

## 驗證

390 × 844 手機瀏覽器重測信義到象山路線，兩筆松仁路工程顯示各自不同的施工時間；來源更新時間為 2026-11-07 22:40:53（臺北時間）。建置通過。
