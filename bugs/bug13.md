# BUG-13：一般公廁目的地的類別在路線結果消失

- 類別：資訊提示／無障礙
- 重現版本：`2c45fa0` 加本輪除錯修復
- 狀態：已修正，瀏覽器重測中

## 重現與資料

固定種子 42 從 `reports/mixed-independent-endpoints.json` 抽出第 28 筆：輪椅設定下選「信義安和(R04)」到「拿坡里南昌店」。搜尋結果顯示目的地為「一般公廁」，成功規劃後目的地只顯示店名，未再說明這是一般公廁或無障礙設施狀況。結果有入口估算、共道與路段資料未知提醒，但那些不等於廁所設施已確認。

目前資料 `toilets-651` 的 `kind` 為 `public-toilet`、`accessibleCount` 為 0；不能僅由該欄位推定現場一定不存在無障礙設施。施工來源更新約 2026-11-07 22:50:54（臺北時間）。

## 程式及修復

`src/data.js` 將 `public-toilet` 標為「一般公廁」，搜尋結果使用該標籤；`src/App.jsx` 的路線結果原僅顯示 `end.name`。新增目的地為一般公廁時的提示，說明無障礙廁所與設施狀況尚未確認，並在朗讀與分享摘要保留同一提醒；不改路線或推斷現場設施情況。

## 驗證

桌面瀏覽器重跑輪椅情境，信義安和到拿坡里南昌店的路線結果顯示一般公廁與狀況未確認提示，入口估算及共道提示仍在；切換大安森林公園示範後公廁提示消失。`npm run build` 通過；朗讀及分享文字已包含同一提示，但本次未實際播放或分享。
