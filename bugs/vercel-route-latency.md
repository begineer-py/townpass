# Vercel 路線規劃耗時

- 功能：從目前位置規劃步行路線，包含施工檢查及人行道比較。
- 2026-11-08 測試：相同石牌站至芝山站請求，本機後端約 0.7–0.9 秒，正式站約 2.1–6.4 秒；該組結果的路線座標一致。這不是使用者的實際起點。
- 正式站回應的 `x-vercel-id` 包含 `hkg1::iad1`：香港入口、維吉尼亞函式。其前端建置及 graph、facilities、places、official-conditions 檔案與當時本機一致。不同請求曾取得不同時間的施工快照。
- 後端 `plan-places` 依序執行人行道改善、候選路線搜尋和避讓資訊；前端另可能等待官方人行道比較。冷啟動及 Vercel 計算資源的個別影響尚未量測。
- 修正：將 Vercel 函式區域設為香港，進入規劃頁時啟動現有預熱。保留路線驗證及比較。部署後應重新量測，確認實際函式區域及耗時；預熱不保證命中同一實例。
- 使用者看到本機與正式站不同的具體起終點和兩邊施工快照未取得，不能據此判定該次差異原因。
