# BUG-15：搜尋服務不可用時誤報找不到地點

- 類別：搜尋／服務故障
- 版本：`1b5b868` 加載入狀態修復 `2b26152`
- 狀態：已修正，桌面瀏覽器重測通過

## 重現

獨立本機服務模擬 `/api/landmark-search` 及 `/data/address-index.json` 回 HTTP 503。搜尋「臺北市信義區永吉路30巷92號」先顯示搜尋中，隨後顯示「還沒找到這個名稱」，沒有指出來源故障。正常服務曾找到該地址；不能把服務錯誤當成沒有匹配結果。

## 原因與修復

`src/address-search.js` 對部分非 2xx 回應回傳空陣列，`src/App.jsx` 則把其他搜尋錯誤當成空結果，搜尋完成後無法區分兩種情況。

```js
if (!response.ok) return [];
```

改為回報搜尋來源失敗；搜尋畫面即使有其他本機結果仍提示部分來源不可用，完全沒有結果時不顯示「找不到」。正常查詢結束且沒有匹配時仍顯示原本提示。這次模擬 HTTP 503，不代表完整離線測試。

## 驗證

桌面瀏覽器在模擬兩來源 HTTP 503 時，地址查詢顯示部分搜尋來源不可用，不再顯示無結果；搜尋「大安森林公園」仍保留本機結果並顯示部分來源不可用。正常服務搜尋不存在字串仍顯示無結果。`npm test` 240／240、`npm run build` 通過；未測完整斷網。
