# BUG-12：施工服務故障被提示為需要連上網路

- 類別：異常處理／資訊提示
- 版本：`2c45fa0` 加上本輪除錯修復，測試施工 API 以獨立服務模擬 HTTP 503
- 狀態：文案已修正，瀏覽器重測中

## 重現

本機測試服務讓 `/api/construction` 固定回傳 HTTP 503，在桌面或 390 × 844 手機頁面選大安森林公園示範；規劃失敗後再按「規劃路線」。起終點保留、沒有路線，安全行為正確；但提示「請連上網路再查一次」。本例網路可用，是服務回傳錯誤，提示不能確定原因。

## 程式與修復

`src/construction-client.mjs` 對 HTTP 失敗、網路錯誤與逾期資料均回傳 `CONSTRUCTION_UNAVAILABLE`；`src/App.jsx` 原本將它統一描述為要求連網：

```js
CONSTRUCTION_UNAVAILABLE: '施工資料暫時無法更新。請連上網路再查一次，附近設施仍可查看。'
```

改成「請確認網路或稍後再試」，保留資料不可用時不提供路線的行為。測試為模擬服務故障，不代表完整斷網行為已驗證。

## 驗證

獨立服務模擬 HTTP 503，桌面瀏覽器重跑大安示範，顯示新文案、保留兩個出入口且沒有產生路線。手機尺寸的同故障情境在修改前已確認安全阻擋；未模擬整體斷網。
