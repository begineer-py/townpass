# BUG-10：定位精度變差後仍可能套用舊位置的回線結果

- 類別：定位追蹤／非同步競態
- 基底版本：`2c45fa0`；另含 `30b7bcb` 提示修復
- 狀態：模組重現並修復；瀏覽器及真實裝置定位尚未驗證

## 功能與重現

以模擬定位送兩筆精度 3 公尺的偏離位置觸發重規劃，在結果返回前送較新的精度 80 公尺位置，再回傳先前 Worker 結果。修復前狀態依序變為重新規劃、不確定、跟隨中；舊位置的路線被採用。預期是在定位不確定時捨棄進行中的舊位置結果，等待可靠定位。

## 原因與程式碼

`src/live-follow.mjs` 收到低品質定位時直接回報 `uncertain`，沒有呼叫 `onPosition`，`src/App.jsx` 的 `session.latest` 保持舊值：

```js
if (invalidPosition) { consecutive = 0; status('uncertain'); return; }
```

因此舊 Worker 結果仍可通過位置比較。重現使用真實追蹤及搜尋模組配合模擬定位和 Worker，並非真實 GPS 紀錄。

## 修復與驗證

不確定定位會清除最新有效位置、取消進行中的回線搜尋並解除待處理狀態；搜尋取消後的過期 Worker 回覆不會發布。新增模組串接測試重現上述先後順序，定位和回線相關測試共 21 項通過，建置通過。尚需以實際瀏覽器及裝置定位確認。

完整 JavaScript 測試 216／216 通過；一般網頁的大安示範與改選起點回歸正常。此回歸未模擬 GPS。
