# 捷運電梯出口未顯示編號 SVG

- 現象：臺北車站 M4、M2 等電梯出口有編號，地圖卻只顯示一般電梯圖示。
- 原因：地圖只將 `metro-exit` 和部分 OSM 出入口歸類為出口符號，排除了 `metro-elevator` 與市府 `wheel-3` 中具明確捷運站出口名稱的資料；名稱同時包含電梯編號與出口編號時，舊解析可能先取到電梯編號。
- 修正：將有明確出口編號的捷運電梯資料顯示為出口 SVG 並加上電梯標記；無出口編號時仍顯示電梯，不猜測出口。優先讀取明確出口欄位與名稱後綴。
- 驗證：臺北車站 M4、M2 及善導寺出口 3 的 SVG 在瀏覽器成功載入，圖標與無障礙文字均保留電梯標示；測試涵蓋不同資料類型與不可推測編號。
