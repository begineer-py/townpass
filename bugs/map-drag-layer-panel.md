# 拖動地圖後人行道線與路線跳動

- 功能：拖動地圖時，既有路線和人行道線應保持穩定；起終點選單不應自行收合。
- 數據：地圖滑動會觸發 `moveend`；舊人行道圖層在讀取新資料前即清空。路線繪製也依賴面板高度，並排程再次調整視野。
- 相關程式：`src/use-sidewalk-layer.js` 的更新流程、`src/MapView.jsx` 的路線 fit 與 `src/App.jsx` 的 `onGesture`。
- 修復：完整載入新視野後再交換人行道圖層；拖動時取消待執行的路線視野調整；起終點輸入面板固定，路線結果面板仍可操作。
- 驗證：人行道載入測試涵蓋完整載入、舊請求取消與讀取失敗；建置通過。實際拖動驗證待瀏覽器操作環境可用時進行。
