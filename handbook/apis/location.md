# 定位

getLocation優先使用台北通location Hook；橋接例外、無效回應或逾時後切換瀏覽器Geolocation。支援addEventListener與onmessage兩種回覆方式，結束時清除監聽。

瀏覽器先一般精度（10秒），定位服務不可用或逾時再試高精度（20秒）；拒絕權限不重試。一般定位誤差超過100公尺會嘗試精化，仍無法精化時只顯示大致位置及誤差圓，不直接設成導航起點。

錯誤區分拒絕、逾時、服務不可用、不支援與非安全來源。新選點會使先前定位回覆失效，避免較慢回覆蓋掉手動選擇。

定位取得可在臺北以外運作，但本服務路網與路線API限定臺北範圍。權限或宿主WebView禁止定位時，網站不能越過系統限制；須由使用者開啟權限。

測試：tests/location.test.mjs。未由代理代替使用者授權或上傳實際位置。
