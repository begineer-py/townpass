# 分級權重與接點搜尋

- 官方人行多邊形完整覆蓋：基礎倍率1.0。
- OSM獨立人行路段：1.8。
- 入口及有官方人行面依據的短銜接：3.5。
- 寬度／坡度缺值、路面及使用者偏好另計代價，並保留未知狀態。

本地路網在使用者最低寬度條件以上，會優先考慮已知較寬路段；偏好目標預設為1.5公尺或最低值加0.3公尺（取較大者），未知寬度給較高代價。這只是待使用者與實地資料校準的排序參數，不是法規門檻或安全分數；候選邊仍受既有車道、過街、施工和使用者限制檢查。資料缺口不能靠權重自動產生路段。

地圖依已知條件以顏色、線型與文字區分寬坡有資料、寬坡未知、可能顛簸及起終點銜接；線條不是安全保證。資料來源類型仍保存在分段中作路由計算，不再用顏色代表來源。官方線路若無逐段寬坡資料，整段標示未知。

接點搜尋半徑50公尺，投影到已存在的人行線段；同一線段上的投影點沿原有幾何連接。多組起終點一起搜尋，包含起終點銜接代價，不先鎖死距離最近的一組。施工影響及不合適入口在搜尋前排除。

投影只用地面人行段，不往橋面做無依據的垂直銜接。保留OSM節點ID，橋上與橋下不因座標相同而相連。明確bridge=yes且footway=sidewalk，或標記wheelchair=yes的獨立人行橋，需有建網產生的高低層證據才保留；樓梯、車道與未知層級仍排除。

3公尺內的地面斷點只在官方人行面完整覆蓋、沒有未證實車道交會且附近無已知障礙時建立銜接。不是任意近鄰自動連線。
