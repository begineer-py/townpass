# 市府平台的位置與路線查詢

2026-11-07 檢查臺北市無障礙通行路線平臺的公開網頁與前端載入的程式：

- 地標搜尋使用 `Z00/taipeiApi` 的 `SEARCHLANDMARK`，要求 `WGS84`，回傳名稱及經緯度。道路地址使用同一介面的 `ADDRESS`。本專案以固定用途的同源介面查詢地標，結果作為一般地點，不視為已驗證的出入口或安全路線。
- 街景網址的 `sceneid` 對應 `C00/C10/C11_streetView/readscene`。實測題目中的場景可取得拍攝日期和 WGS84／TWD97 坐標；這是街景拍攝位置，不是使用者的即時定位。
- 地圖選點轉換坐標後，`navigation_waypoints` 接收經緯度，回傳 TWD97 路線和 `snap_lines` 銜接線。前端繪出銜接線；抽測大安案例的終點銜接線約 138 公尺，不能單憑存在銜接線認定它全程是安全人行空間。
- 這次檢查的兩個官網 JavaScript 模組沒有找到瀏覽器 `geolocation`、`getCurrentPosition` 或 `watchPosition`；不能據此聲稱官網有更好的 GPS 定位方法，也不能排除其他未檢查的程式。
- 官網顯示目前規劃涵蓋實體及標線型人行道，並可能回傳替代路線及問題數量。本專案仍需檢查車道、銜接、施工與資料缺漏。

官網服務可用性與第三方使用條件沒有服務保證；查詢字詞會送至市府服務。本專案不隨地標查詢傳送裝置位置或身分資料。

2026-11-07 比對芝山站出口至兒童新樂園：官方服務有回傳候選路線，但其中一段在承德路六段標記「尚無行穿線」，所以不能直接當成已驗證的安全路線；該案例仍需補足可通行的路口與連續人行圖資。官方可計算出幾何線不等於全程可無障礙通行。
