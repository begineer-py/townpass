# 目前狀態

- 開發分支：codex/accessibility-map-dev；每次驗證後提交並推送。
- 已合併遠端 main 的功能選單與台北通樣式；進站預設展開路線規劃，可收起內容查看全螢幕地圖。
- 保留語音輸入／朗讀、色覺友善設定、手機面板320ms收合。
- 線上路線要通過人行多邊形、過街及入口檢查才顯示；設施點位不等於通行證明。
- 設施46,612筆；補充幾何33,786個。原9組樣本仍有資料缺口；大安通道路網端點684公尺正向案例通過。
- 目前是路線預覽，沒有即時視障導航與現場安全保證。

例行檢查：`npm test`、`npm run build`。詳細數據在 `/reports`；實測紀錄在根目錄 VALIDATION.md。

施工已接入路由：每次線上查詢取得近期通報，遇工區排除相關邊再計算；無合格替代路線就停止指引。詳見[施工API](apis/construction.md)。
