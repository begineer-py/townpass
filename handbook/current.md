# 目前狀態

更新日期：2026-11-07

## 已提供

- 地圖搜尋地點、地址、捷運站與最近儲存行程。
- 首次選擇主要出行方式；其預設路線條件可在設定中調整。
- 初次設定後請求定位，將目前位置設為預設起點並顯示紅色位置點。
- 出行類型與行程記錄保存在瀏覽器 IndexedDB；不支援時使用本機儲存空間。台北通帳號的資料以雜湊帳號識別值區分。
- 三段式底部搜尋面板、功能分頁（找設施、規劃路線、捷運出口、收藏）及浮動圖層工具；手機面板 320ms 收合。
- 語音輸入／朗讀、色覺友善設定。
- 地圖顯示公園與捷運站；詳細卡「我要到這裡」會以目前位置為起點直接規劃。
- 路線可順路停靠 150 公尺內的無障礙廁所或歇腳椅（需連線）；離線規劃會避開今日保養的捷運電梯出口。
- 路線頁可撥打 1999，或在台北通內回報路障。
- 靜態資料由 Vite 打包提供，路線由 Web Worker 驗證。

## 路線規劃

- 線上路線要通過人行多邊形、過街及入口檢查才顯示；設施點位不等於通行證明。
- 施工已接入路由：每次線上查詢取得近期通報，遇工區排除相關邊再計算；取不到施工資料或無合格替代路線就停止指引，不顯示穿過工區的路線。詳見[施工 API](apis/construction.md)。
- 官方候選路線未通過幾何檢查時，先嘗試同一組起終點的本機人行替代路線，仍需通過施工與入口檢查；未找到時列附近捷運電梯出口，選擇後更改端點並重新規劃。
- 多路線搜尋會保持起終點，最多查 8 個途經點並逐一驗證。M2 電梯至中山出口 5 實測 7 條仍未通過；入口官方點距人行面約 1.27 公尺，不能把這個圖資差距直接視為已可通行。
- 人行候選路網 231,555 邊、236,770 節點；設施 46,612 筆；補充幾何 33,786 個。原 9 組樣本仍有資料缺口；大安通道路網端點 684 公尺正向案例通過。
- 例行檢查：`npm test`、`npm run build`。詳細數據在 `/reports`；實測紀錄在 [驗證紀錄](validation.md)。

## 待驗收

- 尚未部署公開 Vercel 網址，也尚未加入台北通服務目錄。
- 台北通 WebView 的 `userinfo` bridge、定位權限與 iOS／Android 真機版面仍待宿主驗收。
- 路線是公開圖資參考；坡度、淨寬、入口、施工與電梯即時狀態並不完整，也未逐段現勘。
- 目前是路線預覽，沒有即時視障導航與現場安全保證。
- VoiceOver、TalkBack、外出使用者與斷網重新開啟流程尚未完成端到端驗收。

## 儲存範圍

出行類型、路線偏好、收藏與行程保存在本機瀏覽器資料庫或本機儲存空間，沒有雲端同步或服務端資料庫。路線查詢只把兩點座標送到 Vercel 函式轉接市府路線服務。
