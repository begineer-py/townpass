# 官方通行線接入路網：幾何容忍度影子試算

這是離線幾何評估，沒有改動正式路由圖。數字不是可導航路線數，也不是無障礙或安全通行率。原始官方線缺少高度、層級、通行權及設施狀況；所有同座標與近距接點均只能作候選，不能自動當成已確認同層通行。

## 方法

使用 60,180 條官方原始 TWD97 線、232,047 條符合既有路由規則且沒有明確橋隧／非地面層標籤的 OSM 行人邊；OSM 未標層級仍為未知，人車共行邊不包含在這次 OSM 接入估算。依序檢查已映射車道線交會是否覆蓋行穿面域、0.5 m 內 OSM 阻障點及當時活動施工，最後才判斷整段是否落在官方面域的緩衝內。來源線端點以 TWD97 原始精確值建立原始共點；其餘近端點銜接與 OSM 邊投影全部標為估計。同一來源分支的兩端不作不同線間接點。使用來源端點範圍 0／0.1／0.5／1／2／3 m、面域容忍度 0／0.25／0.5／1／2／3 m，共 36 組；兩項容忍度獨立。施工資料擷取於 2026-11-08 05:41 臺北時間、來源更新 05:40:50；施工會改變。

「點對」可能包含同一來源端點對多條 OSM 邊；附接分量長度也包括分量中未逐條與 OSM 直接接觸的部分，並不代表每條都可通行。相較 0／0 m，0.5／0.5 m 多出約 206.70 km、1／1 m 多約 301.16 km 的面域幾何候選；其中還有未知來源限制，不能直接計成新增可用路線。

在 3 m 最大搜尋內，來源端點對有 200 次因已映射車道交會未通過而拒絕、165 次因施工、1,698 次因面域不符；另 685 對是同一來源分支兩端，未當不同線路接點。OSM 附接有 1,408 次車道交會拒絕、374 次施工、1,989 次面域不符；沒有進一步被判為阻障點的端點對。這說明若僅按距離吸附，會把有交會風險的連接放入；尚未映射的車道、立體交會和障礙不包含在拒絕數中。資料檢查優先序使各拒絕原因互斥，不能解讀成現實世界的障礙總數。

## 來源、重跑及人工複查

完整 36 組、來源及程式 SHA-256、輸入路徑、版本、逐項計數和 0.5／1 m 真實來源線段 ID 見 `official-sidewalk-tolerance-shadow.json` 的 `sampleSegments`。例子為來源順序中首批通過已知道路、阻障及施工檢查的片段，並非隨機或全市代表樣本。人工複查時用 ID 找回原始官方 WKT，比對街景或現地的道路左右側、坡道、實際交叉口、橋隧與封閉狀況，不能只看線段重疊。實際運行需要 sidecar、同 hash graph、`data/processed/shadow-osm-edges.json.gz` 和同 hash 的未過期施工快照；這些本機工作檔不隨報告公開，過期快照會拒絕重跑。環境為 Python 3.12、Shapely 2.2.0、pyproj 3.8.0，另需原專案 Node 依賴。先執行 `node scripts/export-shadow-osm-edges.mjs` 及 `node scripts/capture-shadow-construction.mjs`，設 `PYTHONPATH` 指向上述版本的獨立依賴，再執行 `py -3.12 scripts/audit-sidewalk-tolerance.py`。新施工快照、原始資料或程式碼改變會得到不同 hash 與結果。

## 產品接入建議

候選圖邊應保存來源 ID、分支索引、原始幾何與雜湊；每個接頭保存連接類型（原始共點或估計銜接）、距離、面域容忍度及道路／阻障／施工檢查結果。以明確 `unknown` 表示未提供的層級、通行權與現場狀況；不要將預設地面或緩衝結果標為已確認。正式導入前應在獨立候選圖比較同一組起終點的完整路線，以新的施工資料和獨立驗證器重驗整段及入口，並用上述案例與跨車道、平面交錯與橋隧等反例做自動回歸及人工核對。對無法確認的連接應維持未知、不中途憑距離跨過車道。
