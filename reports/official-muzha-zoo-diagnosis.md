# 木柵至動物園：官方路線資料診斷

2026-11-07 臺北時間約 22:00–22:05，對第二輪捷運站樣本中的木柵站至動物園站失敗案例，查詢公開臺北市路線 API，並以本地路網的官方面圖資、車道遮罩和新鮮施工資料重新核對。這是資料及計算結果，沒有現場勘查。

## 已觀察結果

- 起點使用木柵站出口無障礙坡道 `metro-exits-2`；終點測試動物園站出口電梯 `metro-exits-0`、`metro-exits-1`。兩個終點皆返回同類結果。
- 官方候選約 2,213 公尺，含 128 個顯示座標；資料回傳 `used_alt=false`、兩類 issues 均為 0、`gap_records=[]`。這些欄位不能替代獨立道路、入口與施工檢查。
- 候選有 43 個顯示線段未完整覆蓋於本地官方人行面，這些**整段**長度約 489 公尺；有 8 個線段與未經官方行穿面覆蓋的車道遮罩相交，這些整段約 131 公尺。兩組數字有重疊，且不是精確的未覆蓋距離。
- 木柵出口至官方線首約 92 公尺，既未完全落在官方人行面，也未通過車道遮罩；動物園兩出口距官方線終點約 2／3 公尺。現行核驗不允許把 92 公尺入口直接畫成可通行線。
- 22:00:41 臺北時間更新的施工快照包含「新光路2段台北市立動物園前」`impact=blocked` 紀錄，其線狀位置與候選相交，現行規則因此阻斷。線狀施工位置的影響範圍為估計，並非精確封閉邊界。

## 首個未通過核驗的線段

官方 API 的 segment index 17、`qgs_fid=157586`，名稱為「木柵路四段」、類型為「通行無礙」。該線段由 `[24.9951493532,121.5718728952]` 至 `[24.9951635190,121.5717240007]`，投影長約 15.112 公尺；對本地官方人行面逐段精確相交，約 0.475 公尺被覆蓋，約 14.637 公尺未覆蓋。現有官方行穿面與它的相交也約 0.475 公尺。

本地 OSM 車道遮罩在該段內有兩個幾何交點，對應 `secondary` 木柵路四段 ways `49774447` 和 `229069820`。原始道路資料沒有明示 layer。官方線段描述、本地多邊形及 OSM 道路遮罩不一致；這不能證明現場沒有行穿線或一定危險，也不能把整段當作已核驗人行道。

## 繞路測試

以首個未覆蓋段中心為基準，由 `createDetourWaypoints` 取得 7 個候選點，向同一官方 API 查詢，使用相同起終點與獨立驗證：

| 結果 | 數量 |
|---|---:|
| 官方回傳後獨立面圖資核驗為 `OFFICIAL_PATH_UNVERIFIED` | 5 |
| 官方候選明示缺少行穿，正規化為 `OFFICIAL_CROSSING_UNVERIFIED` | 2 |
| 通過既有完整核驗的候選 | 0 |

另外對 5 條未覆蓋候選逐段核對：每條起點 snap 均約 92 公尺，入口不符合人行面及車道檢查；各有 41–46 個未完整覆蓋線段和 8–9 個車道衝突，且均與該施工通報相交。單純放寬面覆蓋門檻，仍不能產生符合現行入口及施工限制的完整路線。

## 重現方式

在專案根目錄啟動 `npm run dev`，確保本機 `/api/accessible-route`、`/api/construction` 可用，使用以下公開捷運出口座標：

```js
const start = [24.9980328, 121.5732164]; // 木柵站出口無障礙坡道
const end = [24.9982136, 121.5797157];   // 動物園站出口電梯1
const center = [24.995156436107933, 121.57179844790826];
```

以 `src/official-router.mjs` 的 `requestOfficialRoute` 查詢並正規化；用 `src/verify-official-route.mjs` 的 `createOfficialRouteVerifier` 核對候選，接著用 `src/construction.mjs` 的 `createConstructionChecker` 檢查 `[start, ...route.coordinates, end]`。以 `src/alternative-routes.mjs` 的 `createDetourWaypoints(graph)(start,end,center)` 重現繞路點，再使用 `{via}` 查詢。面覆蓋及車道統計使用 `officialGeometryEvidence(graph)` 和 `polygonConnectorChecker`／`roadConnectorChecker` 對每個相鄰座標段計算。

施工及官方服務會更新；查詢可能回傳服務不可用、不同候選或不同施工結果。當時圖資、來源與程式詳見版本庫；不要把線狀施工位置、官方候選或缺失標籤當成現場可通行的保證。
