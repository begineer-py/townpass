# 多候選路線：固定站點樣本

2026-11-08 臺北時間約 00:16，使用先前固定種子的 60 組捷運站對，透過實際本機 worker 執行多候選搜尋；施工來源更新時間為 00:10:45。每條候選均依當時路網、偏好及施工資料檢查，部分路段不計作抵達。此測試不涵蓋官方線上路由、實際 GPS 或現場通行，也不是全市成功率。

| 指標 | 結果 |
|---|---:|
| 至原選點的完整路線 | 47/60 (78.3%) |
| 另有部分路段，尚未完整抵達 | 13/60 |
| 成功路線中至少兩條不同候選 | 19/47 (40.4%) |
| 成功路線含未確認估算銜接 | 45/47 (95.7%) |
| 明示 sidewalk／選中路線完整距離 | 74.8% |
| 已繪製人行路網（含 sidewalk 與其他 path 等）／完整距離 | 92.4% |
| 可能人車共行／完整距離 | 6.9% |
| 估算銜接／完整距離 | 0.6% |
| 成功請求耗時中位數／P95 | 約 2.25／4.00 秒 |

人行路網含 OSM `path` 等，不等同已確認人行道；按本次評分使用的路寬、坡度、路面或過街資料，約 99.3% 的選中路段長度至少有一項未知。耗時不含 worker 載入及網路。其餘 28 組成功路線只找到一條符合去重及時間限制的候選，不代表現場沒有其他路線。多候選分數只是依資料及距離的排序，不是安全或無障礙認證。

明細及各候選的距離、分數、路段分類及搜尋狀態見 `multiple-routes-stations-current.json`。資料快照會更新，重跑可使用 `node scripts/benchmark-multiple-routes.mjs`；本次施工快照未另存，僅保留來源時間與內容 hash，無法保證日後完全重現當時施工條件。
